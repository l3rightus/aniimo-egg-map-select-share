# Aniimo Egg Map — Select & Share

เว็บสำหรับสร้างห้อง ให้หัวหน้าห้องเลือกแมพ แล้วแชร์ลิ้งให้เพื่อน
ทุกคนที่เข้าลิ้งจะเห็นแมพเดียวกับที่หัวหน้าห้องเลือก และเปลี่ยนตามทันทีเมื่อหัวหน้าเปลี่ยนแมพ (real-time)

## วิธีใช้

1. เปิดหน้าแรก กด **สร้างห้องใหม่** → คุณจะเป็นหัวหน้าห้อง
2. เลือกแมพจากแถบด้านบน
3. กด **คัดลอกลิ้งแชร์** แล้วส่งให้เพื่อน (หรือให้เพื่อนกรอกรหัสห้อง 6 ตัวที่หน้าแรก)
4. เพื่อนจะเห็นแมพเดียวกัน และเปลี่ยนตามอัตโนมัติ ซูม/เลื่อนแมพได้เอง (ล้อเมาส์, ลาก, pinch บนมือถือ, ดับเบิลคลิก)

> ปุ่ม **ลิ้งหัวหน้าห้อง** ใช้เปิดห้องในฐานะหัวหน้าบนอุปกรณ์อื่นของคุณเอง — อย่าแชร์ให้คนอื่น

## รัน

ต้องใช้ Node.js 18 ขึ้นไป ไม่มี dependency ภายนอก

```bash
npm start          # http://localhost:3000  (เปลี่ยนพอร์ตด้วย PORT=8080 npm start)
npm test
```

## เพิ่ม/เปลี่ยนแมพ

วางไฟล์รูป (`.webp`, `.png`, `.jpg`) ไว้ใน `public/maps/` แล้วรีสตาร์ท server
แมพจะเรียงตามชื่อไฟล์ และแสดงชื่อเป็น "แมพ 1", "แมพ 2", …

## หมายเหตุการ deploy

- ห้องเก็บในหน่วยความจำ (in-memory) ถ้า restart server ห้องจะหายไป ห้องที่ไม่มีคนอยู่เกิน 24 ชม. จะถูกลบอัตโนมัติ
- ใช้ Server-Sent Events สำหรับ real-time จึงต้องรันเป็น server ที่เปิดค้างได้ (เช่น Render, Railway, Fly.io, VPS) — ใช้กับ static hosting หรือ serverless แบบ GitHub Pages / Vercel functions ไม่ได้
- รันแค่ instance เดียว (ห้องไม่ได้แชร์ข้าม instance)
